# Digital Multiverse of Our Relationship ✨

A digital multiverse and eternal archive compiled by **Arjun** for his beloved **Lechu**, commemorating the day the universe changed on **October 6, 2023**.

## Tech Stack
- **React 19** + **Vite 8**
- **Three.js** (Interactive 3D particle system with 2,800 responsive particles)
- **Framer Motion** (Fluid animations, transitions, and timeline triggers)
- **Tailwind CSS v4** + Modern Typography (Cinzel, Outfit, JetBrains Mono)
- **Web Audio API** (Custom procedural synth chords and ambient heartbeats)
- **Canvas Confetti** + **Lucide Icons**

---

## How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to:
```
http://localhost:5173
```

### 3. Unlock the Multiverse
1. On the Gateway screen, enter the anniversary date: **`10-06-2023`** (or **`06-10-2023`**).
2. The temporal warp will unlock into the full interactive experience.

---

## Features
- 🌌 **Starfield Background**: Infinite twinkling canvas with dynamic nebula glows and shooting stars.
- 🔐 **Temporal Gateway**: Interactive security lock with vibration feedback and cosmic warp transition.
- ⏱️ **Live Convergence Clock**: Real-time counter calculating elapsed days, hours, minutes, and seconds since Oct 6, 2023.
- 📸 **Memory Constellation Gallery**: Glass Polaroid photo cards with 3D hover tilt physics, category filters, interactive heart reactions (sparkling confetti & chimes), and a cinematic full-screen lightbox modal.
- 📜 **Chrono-Spatial Timeline**: Alternating milestone cards detailing key coordinates from Genesis to Eternity.
- 🎶 **Cosmic Soundtrack**: Curated romantic songs from `public/music` with a dedicated song gallery and a floating glassmorphism player dock with spinning vinyl visuals, seek bar, queue view, and shuffle/repeat controls.
- 🎵 **Zero-Asset Procedural Audio**: Ambient synthesizers, heartbeat pulses, and ethereal chords using browser Web Audio.

## 📷 How to Add Your Own Photos

1. **Add Your Images:**
   Place your personal photos inside the **`public/photos/`** folder:
   - `public/photos/photo1.jpg`
   - `public/photos/photo2.jpg`
   - `public/photos/photo3.jpg`
   - `public/photos/photo4.jpg`
   - `public/photos/photo5.jpg`
   - `public/photos/photo6.jpg`
   *(You can add as many as you like; `.jpg`, `.png`, or `.webp` formats work).*

2. **Customize Titles & Notes:**
   Open [`src/components/MemoryGallery.jsx`](file:///home/arjunr/back-up/Desktop/Aniti-gravity/profolio%20projects/Digital%20Multiverse%20of%20Our%20Relationship/src/components/MemoryGallery.jsx) and edit the `memories` list with your real dates, locations, and personal love notes!
